准备curl.txt 
1.登录fab
2.按图片的方式 获取一下curl.txt 很重要
3.保存curl.txt 注意这份代码比较 重要不要丢，在本地放好。 不要泄露，不要泄露，不要泄露

准备请绪后
1.运行get.py 目的，获取所有免费资产； 得到fab.txt。如果太快限制频率， 可修改一下有备注； 我会偶尔的上传一下， 你可以跳过这步省一些api的限制（这个py带有断点续传的功能，断掉后直接重新运行即可，重新获取删除 lastCursor.txt）

5.compare.py 目的，自动下单  所有资产都 会完成。
