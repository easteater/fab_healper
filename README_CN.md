# Fab 资产自动添加入库，自动购买 (数据库驱动版)
# Fab 资产自动领取脚本操作手册
 
> **核心逻辑**：以 `fab_data.db` 数据库为核心，通过 `curl.txt` 模拟身份，自动化执行“扫描 -> 校验 -> 取码 -> 下单 -> 验收”闭环。

---

## 🛠 准备工作 (Preparation)

1.  **身份凭证 (`curl.txt`)**
    * **获取方式**：登录 Fab 官网 -> F12 网络 (Network) -> 找 `listings-states` 请求 -> 右键 `Copy as cURL (bash)`。
    * **存储**：将内容粘贴至 `curl.txt`。
    * **注意**：此文件含敏感 Token，**严禁泄露**。若报错 403 请重新获取。

2.  **环境要求**
    * Python 3.x
    * 安装依赖：`pip install curl_cffi` (必须使用，用于绕过 TLS 指纹检测)。

---

## 🚀 脚本执行流程 (Workflow)

### 1. 资产扫描阶段：`get.py`
* **功能**：获取 Fab 所有免费资产 UID，直接写入数据库 `fab_assets` 表。
* **断点续传**：自动读取/更新 `lastCursor.txt`。
* **新增逻辑**：检测到连续 10 个已存在记录自动停止（可加参数 `0` 强制全量扫描）。

### 2. 数据校验阶段：`compare.py`
* **功能**：调用官方接口校验库中未入库资产。
* **产出**：
    * **更新数据库**：将已拥有的资产 `is_acquired` 状态改为 1。
    * **日志**：生成 `unacquired_list.log` (记录当前仍未拥有的资产)。

### 3. 下单准备阶段：`getOfferId.py`
* **功能**：请求详情页获取下单所需的 `offerId`。
* **产出**：更新数据库中的 `offer_id_1` 和 `offer_id_2` 字段。支持双许可资产同时抓取。

### 4. 自动化下单阶段：`claim.py`
* **功能**：从库中提取有 `offerId` 的记录执行 0 元购买动作。
* **注意**：**此脚本不改动库状态**。支持同一个 UID 连续下两次单（对应俩 OfferID）。建议设置 `DELAY` 防止风控。

### 5. 战果验收阶段：`compare.py` (再次运行)
* **功能**：下单后再次执行，通过官方接口核实并更新数据库 `is_acquired` 状态为 1。

---

## ⚠️ 开发者注意事项 (Technical Notes)

* **路径依赖**：`.py` 脚本及 `db.py` 必须与 `curl.txt` 在同一层级目录下。
* **数据一致性**：一切状态以 `compare.py` 校验为准，下单脚本 `claim.py` 只负责执行不负责统计。
* **频率限制**：如提示 `429` 或 `403`，请检查 `curl.txt` 是否失效，或调大 `time.sleep()`。
